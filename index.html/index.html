Yapısal Etiketler

Html = Belgesinin başlangıcı ve sonu.

Head = Sayfa hakında bilgiler.(başlık,meta,sitil vs.)

Body = Sayfa içeriğinin bulunduğu kısım.

Titler = Tarayıcı sekmesinde görünen başlık.

Metin Biçimlendirme Etiketleri

H1-H6 = Başlık etiketleri büyükten,küçüğe doğru.

P = Parağraf için kulanılır.

B veya Strong = Kalın yazı.

I veya Em = İtalik yazı.

U = Altı çizili yazı.

Br = Satır sonu.(yeni satır)

Hr = Yatay çizgi.(ayırıcı çizgi)

Bağlantı Ve Görsel Etiketleri

A = Bağlantı (link) oluşturu.

Ing = Görsel ekler.

Video = Video ekler.

Audio = Ses ekler.

Liste Etiketleri

Ul = Sırasız liste.(madde işaretli)

Ol = Sıralı liste.(numaralı)

Li = Liste elemanı.

Yapı Ve Bölümleme Etiketleri

Div = Bölüm oluşturur.(blok elaman)

Span = Küçük metin bölümü.(satır içi eleman)

Header = Sayfa başlığı alanı.

Footer = Sayfa alt bilgisi.

Nav = Menü veya gezinme alanı.

Section = Sayfa bölümü.

Article = Bağımsız içerik.(makale,yazı vs.)

Tablo Etiketleri

Table = Tablo oluşturu

Tr = Tablo satırı

Td = Tablo hüçresi

Th = Başlık hüçresi

Caption = Tablo başlığı

Form Etiketleri

Form = Form alanı

Inpat = Kullanıcıdan veri girişi alır.

Textarea = Çok satırlı metin girişi.

Button = Buton oluşturur.

Select = Açılır liste.

Option = Açılır liste eleman

Label = Form elemanlarına açıklama ekler.
